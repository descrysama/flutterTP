# TP Flutter – Menu d'un restaurant

Application Flutter qui affiche le menu d'un restaurant. On choisit une
catégorie (Formules, Entrées, Plats, Desserts, Boissons) dans la barre en haut
et les plats correspondants s'affichent sous forme de cartes. On peut cliquer
sur un plat pour voir son détail.

Pour lancer le projet :

```bash
flutter pub get
flutter run
```
